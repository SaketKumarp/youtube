# 🎬 AI-Powered YouTube Clone

A modern, scalable, AI-powered video streaming platform built using Next.js, TypeScript, tRPC, React Query, Tailwind CSS, and Clerk Authentication.

This project is evolving into a production-level intelligent streaming platform inspired by YouTube and Netflix, combined with AI/ML systems for smart recommendations, semantic search, personalized feeds, and advanced creator analytics.

# ⚙️ Getting Started

## Clone Repository

```bash
git clone https://github.com/SaketKumarp/youtube.git
cd your-project-name
```

---

## Install Dependencies

```bash
npm install

# or

pnpm install

# or

yarn install

# or

bun install
```

---

## Setup Environment Variables

Create `.env.local`

```env
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in
NEXT_PUBLIC_CLERK_SIGN_UP_URL=/sign-up
NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_URL=/
NEXT_PUBLIC_CLERK_SIGN_UP_FALLBACK_URL=/


DATABASE_URL=
CLERK_WEBHOOK_SIGNING_SECRET=

 

OPENAI_API_KEY=

# Future AI integrations
VECTOR_DB_URL=
ML_SERVICE_URL=
```

---

## Run Development Server

```bash
npm run dev

# or

pnpm dev

# or

yarn dev

# or

bun dev
```

Open:

```bash
http://localhost:3000
```
